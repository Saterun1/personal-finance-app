# Учёт личных финансов

Desktop-приложение для учёта доходов и расходов: ООП, графический интерфейс
на Tkinter, хранение данных в **Excel-книге** (`.xlsx`) и простая аналитика.

## Возможности

- Добавление доходов и расходов с указанием суммы, категории, даты и описания
- Классификация операций через `Enum` (`Доход` / `Расход`)
- Автосохранение в Excel и автоматическая загрузка данных при запуске
- Расчёт баланса, сумм доходов и расходов
- Аналитика по категориям и динамика по месяцам
- Фильтры по типу, категории и месяцу, поиск по описанию
- Сортировка таблицы кликом по заголовку колонки
- Свои категории через меню «Категории»
- Экспорт данных в отдельную Excel-книгу

## Требования

- Python 3.9+
- `openpyxl` — для чтения и записи Excel-файлов
- Tkinter входит в стандартную поставку Python для Windows и macOS.
  На Linux: `sudo apt install python3-tk`

## Запуск

```bash
pip install -r requirements.txt
python finance_gui.py
```

Демо-данные для первого запуска:

```bash
python generate_demo_data.py
```

## Тесты

```bash
python -m pytest test_finance_classes.py -v
# или без pytest
python test_finance_classes.py
```

Тесты покрывают модели данных, аналитику, фильтры и работу с Excel-файлом
(включая обработку повреждённых строк и повреждённого файла). Графический
интерфейс тестами не затрагивается.

## Архитектура

### `finance_classes.py`

| Класс / функция     | Назначение |
|---------------------|------------|
| `TransactionType`   | Перечисление типов операций: `INCOME`, `EXPENSE` |
| `Category`          | Категория доходов или расходов |
| `Transaction`       | Одна операция: сумма, категория, дата, описание |
| `FinanceManager`    | Управление операциями, аналитика, чтение и запись Excel |
| `parse_date`        | Разбор даты в формате `ГГГГ-ММ-ДД` |

`Transaction` и `Category` реализованы как `dataclass`: поля описываются
в конструкторе, а `__post_init__` проверяет корректность данных. У суммы
отрицательное значение недопустимо — знак операции задаётся типом категории,
поэтому у `Transaction` есть свойства `is_income` и `signed_amount`.

`FinanceManager` отвечает за:

- хранение списка операций и справочника категорий;
- `add_transaction` / `delete_transaction` / `clear` с автоматическим
  сохранением в Excel;
- аналитику: `get_balance`, `get_income_total`, `get_expense_total`,
  `get_category_summary`, `get_monthly_summary`;
- фильтрацию `get_transactions` по типу, категории, месяцу и поисковой строке;
- `save_to_file` и `load_from_file` (открытие книги через `openpyxl`).

Повреждённые строки Excel пропускаются при загрузке, а не приводят к падению:
если в файле встретилась неизвестная категория, она создаётся автоматически,
так что ручное редактирование книги не ломает приложение. Если файл вообще
не является книгой Excel, приложение стартует с пустым списком операций.

### `finance_gui.py`

Класс `FinanceApp` отвечает за окно и разделяет ответственность так:

- `_build_input_frame` — форма добавления операции;
- `_build_info_frame` — карточки с балансом, доходами, расходами и количеством
  операций;
- `_build_filter_frame` и `_build_table` — фильтры, поиск и таблица `Treeview`;
- `add_transaction`, `delete_selected`, `sort_by`, `show_analytics` — действия
  пользователя.

Логика расчётов живёт в `FinanceManager`, а не в обработчиках кнопок, поэтому
интерфейс можно заменить или покрыть тестами независимо. Суммы в таблице
выводятся с разделителем разрядов, а цвета строк показывают тип операции:
зелёный для дохода, красный для расхода.

## Формат данных

`transactions.xlsx` — обычная книга Excel с двумя листами.

Лист **«Операции»** — таблица с оформленным заголовком, автофильтром
и закреплённой первой строкой:

| Amount | Category | Type | Date | Description |
|--------|----------|------|------|-------------|
| 95000 | Зарплата | Доход | 2025-01-15 | Зарплата за месяц |
| 2500 | Продукты | Расход | 2025-01-16 | Продукты |

- `Amount` — сумма операции (число), всегда положительная;
- `Type` — `Доход` или `Расход`, определяется категорией;
- `Date` — дата в формате `ГГГГ-ММ-ДД` (принимается и «настоящая» дата Excel).

Лист **«Аналитика»** создаётся автоматически при каждом сохранении: суммы по
категориям, итоги и динамика по месяцам.

Книгу можно править прямо в Excel: при следующем запуске изменения
подхватятся, а неизвестные категории будут добавлены автоматически.

## Управление

| Действие | Как |
|----------|-----|
| Добавить операцию | Кнопка «Добавить» или `Enter` в поле описания |
| Удалить операцию | Кнопка «Удалить выбранную» или клавиша `Delete` |
| Аналитика | Кнопка «Показать аналитику» |
| Сортировка | Клик по заголовку колонки, повторный клик меняет порядок |
| Перенести в форму | Двойной клик по строке таблицы |
| Сбросить фильтры | Кнопка «Сбросить» |
